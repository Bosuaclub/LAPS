📝 Quick Start: Streamlit Cloud (Recommended)

  1. Push your code to GitHub (if not already done)
  2. Go to share.streamlit.io
  3. Sign in with GitHub
  4. Click "New app" and select your repository
  5. Set main file path to: faosim/ui/app.py
  6. Add your API keys in Settings → Secrets
  7. Click "Deploy!" - Done! ✅
# Example Streamlit Cloud secrets.toml [openai] api_key = "sk-..." [anthropic] api_key = "sk-ant-..."
